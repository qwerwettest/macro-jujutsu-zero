# Макрос рейда Махито (Jujutsu Zero, Roblox)

Проходит рейд Махито по кругу:

1. Нажимает **Ready**, выбирает технику клавишей **1**.
2. Идёт к маркерам групп НПС (сначала левый, потом правый), на месте жмёт **F**, пока маркер не погаснет.
3. Бьёт босса способностями **R F X C**, при низком HP уворачивается на **Q**.
4. Принимает награды (**Next → Close → Retry**) и запускает рейд заново.

Считает статистику: рейды, кристаллы и сундуки, за сессию и за всё время. Есть Telegram-бот: статистика, состояние, старт/пауза, скриншот. Уведомления в Telegram и Discord приходят только при ошибках.

Если этап рейда завис дольше 2 минут (например, игра не заспавнила босса), макрос делает респавн (**Esc → R → Enter**) и начинает рейд заново. Такой рейд в статистику не попадает.

## Установка

1. Поставь **Python 3.10+** с [python.org](https://www.python.org/downloads/). При установке отметь галочку **Add Python to PATH**.
2. Скачай репозиторий (или `git clone`) в любую папку.
3. Запусти `install.bat` (или в терминале `python -m pip install -r requirements.txt`).
4. Скопируй `config.example.json` в `config.json`. Как его заполнить, описано ниже. Без `config.json` макрос работает, но без бота и уведомлений.

## Подключение Telegram-бота

1. Создай бота. В Telegram открой [@BotFather](https://t.me/BotFather), отправь `/newbot`, придумай имя и username (должен оканчиваться на `bot`). BotFather пришлёт **токен** вида `1234567890:AAE...`.
2. Впиши токен в `config.json`:
   ```json
   {
     "telegram": {
       "bot_token": "1234567890:AAE...",
       "allowed_chat_id": ""
     },
     "discord_webhook": ""
   }
   ```
3. Узнай свой chat_id. Запусти макрос (`start_mahito.bat`) и напиши боту в Telegram что угодно, например `/start`. Пока `allowed_chat_id` пустой, бот ответит: «Твой chat_id: 123456789».
4. Впиши это число в `allowed_chat_id`, например `"allowed_chat_id": "123456789"`, и перезапусти макрос.
5. Напиши боту `/menu` (или любой текст), выбери «Рейд Махито» и нужную кнопку:
   - 📊 **Заработано**: рейды, кристаллы и сундуки за сессию и за всё время
   - ℹ️ **Состояние**: работает или на паузе, текущая фаза, время рейда
   - ⏯ **Старт / пауза**: то же, что F8
   - 🖼 **Скриншот**: снимок экрана

Бот отвечает только на chat_id из конфига. Бот живёт внутри макроса: пока макрос не запущен, бот молчит.

> Один токен может опрашивать только одна программа. Если тот же бот уже запущен на другом ПК или в другом скрипте, в логе будет «бота уже опрашивает другой запущенный скрипт». Для нового ПК лучше сделать отдельного бота.

### Discord (по желанию)

Настройки канала → Интеграции → Вебхуки → Новый вебхук → «Копировать URL». Вставь URL в `"discord_webhook"`. Туда придут те же уведомления об ошибках.

## Запуск

1. Зайди в игру, встань в лобби рейда Махито (где кнопка **Ready**). Окно Roblox должно быть на переднем плане, свёрнутое окно макрос не трогает.
2. Запусти `start_mahito.bat`.
3. Нажми **F8**, чтобы начать или поставить на паузу. **End** закрывает макрос.

Чтобы начать сразу без F8, запусти так: `start_mahito.bat --on`.

### Требования к игре

- Техника стоит в слоте **1**. Способности: **R F X C** против босса, **F** против групп НПС, **Q** для уворота.
- Камеру не крутить: движение идёт по WASD относительно камеры.
- Окно Roblox называется `Roblox`. Размер окна любой: снимок приводится к ширине 1920. Но надёжнее всего полноэкранный режим 1920×1080.

## Настройки

Все настройки передаются аргументами, например `start_mahito.bat --keys r f x c --stage-max 150`:

| Аргумент | По умолчанию | Что делает |
|---|---|---|
| `--keys` | `r f x c` | способности против босса по кругу |
| `--fight-key` | `f` | способность против группы НПС |
| `--equip-key` | `1` | клавиша выбора техники |
| `--dodge-key` / `--low-hp` | `q` / `0.35` | уворот, когда своё HP ниже 35 % |
| `--arrive-m` | `8` | за сколько метров до маркера считать, что дошёл |
| `--kill-wait` | `10` | сколько секунд ждать, пока маркер погаснет, потом сдвинуться |
| `--stuck-sec` / `--detour-sec` | `4` / `1.5` | застрял (расстояние не уменьшается), значит обходить препятствие |
| `--jump-count` / `--jump-gap` / `--jump-pause` | `3` / `0.1` / `1.0` | серии прыжков по пути |
| `--stage-max` | `120` | этап дольше стольких секунд ведёт к респавну |
| `--stuck-min` | `10` | через сколько минут без кнопок рейда прислать «застрял» |
| `--window` | `Roblox` | заголовок окна игры |

Полный список: `python mahito_raid.py --help`.

## Полезное

- `python mahito_raid.py --stats` показывает статистику без запуска.
- `python mahito_raid.py --test путь/к/скриншоту.png` проверяет, что макрос распознаёт на скриншоте: кнопки, маркеры с расстоянием, HP босса, награды.
- Лог пишется в `mahito.log`, статистика хранится в `mahito_stats.json`.
- Если награды не прочитались, снимок сохраняется в `snaps/mahito_unread/`, и приходит уведомление.
